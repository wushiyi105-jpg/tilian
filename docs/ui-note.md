# UI 说明：题练

- **谁在什么时刻打开**：给用自己的材料备考的人。
- **首屏任务句**：今天，复习几题。
- **主操作**：按「选讲义和题量 → 作答不先看答案 → 按错因回排」推进；首屏先给输入和主按钮，结果区在下方或右侧。
- **主信息结构**：分栏纸质习题册；对比、时间线、原文与修订、队列或价签按任务选择，而不是通用卡片堆叠。
- **三种状态**：空状态指到第一步；已有内容显示结果、来源/计算依据和导出入口；失败或待确认时保留已填内容，并在原位置说明缺什么。
- **视觉原型**：分栏纸质习题册。底色、强调色、圆角、边框和数字字体都按该任务重定，遮住产品名后仍能从布局看出用途。
- **解释**：给用自己的材料备考的人：题目附来源段落，答完给错因，讲义支持的等价答案可以接受，答对但犹豫的单独回排。
